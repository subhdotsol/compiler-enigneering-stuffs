# compiler eng

Welcome to my compilers learning dump. This is where I scan, parse, and occasionally segfault my way through learning how compilers actually work.

Think of this repo as my brain's intermediate representation. Messy, unoptimized, and nowhere near ready for codegen.

## What lives here

Notes, diagrams, half baked experiments, and whatever else survives my personal garbage collector.

```
notes/    chapter by chapter notes and diagrams
```

More directories will appear as I learn things. Lazy evaluation, but for folders.

## Why

Because one day I want to look at a compiler error and feel empathy instead of rage.

Also because writing a compiler is the closest a programmer gets to building their own universe, except the universe throws `unexpected token` at you every five minutes.

This is a personal learning log, so there is not much to contribute. But if you spot something wrong in my notes, open an issue. I promise to handle it better than a C compiler handles a missing semicolon.
